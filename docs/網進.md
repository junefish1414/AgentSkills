# 網進

> 本文件為團隊內部黑話字典條目，主要供 AI 理解 104 招募管理系統（B 端 / 求才端）的核心商業概念與術語慣例。

---

## 網進產品

**所屬端**：B 端（求才端 / 企業招募管理系統）

**定義**：104 提供給企業客戶的產品總稱，為**上位概念**。底下主要分為：

- **刊登方案**：提供刊登天數、暫停天數等基礎徵才服務的方案。
- **加值產品**：提供各項加值服務的產品。
- **專員包套**：容納刊登方案及加值產品的特殊套餐。

**相關概念**：刊登方案、加值產品、專員包套

---

## 刊登方案

**定義**：網進產品之一，主要提供**刊登天數**、**暫停天數**的方案。

**底下分類**：

- **標準刊登方案**：只提供刊登天數的方案。
- **刊登套餐**：在標準刊登方案的基礎上，再提供贈送刊登天與贈送/合購加值產品的優惠方案。

**異動紀錄**：

- **2026/5/1**：下架 7 天、14 天商品。

**相關概念**：網進產品、標準刊登方案、刊登套餐

---

## 標準刊登方案

**定義**：刊登方案之一，**只提供刊登天數**的方案，不含贈送刊登天或加值產品。

**以刊登天數區分的稱謂**：

| 刊登天數 | 稱謂                |
| -------- | ------------------- |
| 7 天（已下架）  | 新客體驗方案        |
| 14 天（已下架） | 14 天標準刊登方案   |
| 30 天    | 30 天標準刊登方案   |
| 60 天    | 60 天標準刊登方案   |
| 90 天    | 90 天標準刊登方案   |
| 180 天   | 180 天標準刊登方案  |
| 365 天   | 365 天標準刊登方案  |

> 💡 7 天方案的稱謂為「新客體驗方案」，並非「7 天標準刊登方案」。

**相關概念**：刊登方案、刊登套餐

---

## 刊登套餐

**定義**：刊登方案之一。除了提供刊登天數，還會額外提供**贈送刊登天**與**贈送/合購加值產品**的優惠方案。

**以配套的標準刊登方案區分的稱謂**：

| 配套的標準刊登方案    | 刊登套餐稱謂      |
| --------------------- | ----------------- |
| 14 天標準刊登方案     | 14 天刊登套餐（已下架） |
| 30 天標準刊登方案     | 30 天刊登套餐     |
| 60 天標準刊登方案     | 60 天刊登套餐     |
| 90 天標準刊登方案     | 90 天刊登套餐     |
| 180 天標準刊登方案    | 180 天刊登套餐    |
| 365 天標準刊登方案    | 365 天刊登套餐    |

**重要規則**：

- 💡 **新客體驗方案（7 天）不會配套成刊登套餐**。
- 💡 刊登套餐**不會有贈送/合購企業形象**。
- 💡 贈送的加值產品中，**加強曝光、自動排序都會有使用期限**；唯獨**企業形象**是以「購買使用天數」計算。
- 💡 **加值套餐不會送刊登天**（刊登套餐才會送刊登天）。
- 💡 刊登套餐、加值套餐**可從後台設定購買條件**，例如：限定「廣告刊登狀態 OFF 時長在幾天內」的公司才可以購買。

**相關概念**：刊登方案、標準刊登方案、加值產品、加值套餐

---

## 加值產品

**定義**：網進產品之一，主要提供各項**加值服務**。

**底下分類**：

| 類型           | 說明                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------ |
| 標準加值品     | 購買來源為**單一**的加值服務，亦即並非透過加值套餐、刊登套餐所提供的加值服務。              |
| 加值套餐       | 加值產品之一，將各種加值服務**打包販賣**，並可給予折扣（套餐本身的折扣）。                  |

**加值品**：指**加值套餐、刊登套餐中所合併販賣或贈送的加值服務**。與「標準加值品」的差別在於**購買來源**——加值品來自套餐，標準加值品為單獨購買。

**重要規則**：

- 💡 **加值套餐不會送刊登天**（與刊登套餐的差異）。
- 💡 加值服務的期限計算：加強曝光、自動排序有**使用期限**；企業形象為**購買使用天數**。

**相關概念**：網進產品、加值服務、刊登套餐、加值套餐

---

## 加值服務

**定義**：額外提供給公司使用的功能。為加值產品（標準加值品、加值套餐等）實際販賣或贈送的內容。

**項目**：

| 加值服務 | 作用對象 | 說明                       |
| -------- | -------- | -------------------------- |
| 企業形象 | 公司     | 提供公司「企業形象」功能   |
| 加強曝光 | 職務     | 提供職務「加強曝光」功能   |
| 自動排序 | 職務     | 提供職務「自動排序」功能   |
| 甄試流程 | 甄試流程 | 提供「甄試流程」功能       |

**相關概念**：加值產品、加值品、加值套餐

---

## 專員包套

**定義**：網進產品之一，為**容納刊登方案及加值產品的特殊套餐**。

**重要規則**：

- 專員包套需要從 **CRM 系統**操作，才能將特殊套餐提供給特定公司。
- 屬於針對特定公司的客製化套餐，並非一般客戶可自行選購的標準商品。

**相關概念**：網進產品、刊登方案、加值產品

---

## 網進流程

**定義**：客戶購買網進產品的作業流程。依購買內容分為兩種：

| 流程     | 說明                               |
| -------- | ---------------------------------- |
| 一般網進 | 購買刊登方案、加值產品的網進流程   |
| 加值網進 | 只購買加值產品的網進流程           |

**相關概念**：網進產品、刊登方案、加值產品
